Gyan Quest

An interactive, mission-based learning platform that turns school subjects into engaging Canvas 2D games.

Md Tahsan Islam · Mufrid Johanee

The Challenge

Students often experience subject learning as passive and repetitive. GyanQuest transforms curriculum practice into active, game-based missions with instant feedback and progress tracking.

Objectives

  • Convert learning objectives into meaningful game missions.
  • Make subject practice interactive through Canvas 2D experiences.
  • Support progress tracking and mission continuity.
  • Provide optional AI guidance without blocking offline gameplay.
  • Create a scalable shared engine for new subjects and lessons.

Methodology

Curriculum Mapping: turn learning objectives into focused game missions.
Game Design: build levels, rules, rewards, and clear feedback loops.
Development: implement reusable Canvas 2D game modules and persistence.
Iterate & Improve: assess engagement, progress, and learner feedback.

Why Gyan Quest?

  • 28 subject-based educational games.
  • Offline-first: core gameplay works without login.
  • Progress resumes exactly where the learner stopped.

Curriculum Coverage

Each game package combines a subject, level, mission rules, and learning prompts. This makes new content easier to add without rebuilding the platform.
