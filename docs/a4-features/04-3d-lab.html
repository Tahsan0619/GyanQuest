3D Lab

Specimen Lab - orbit real 3D models

Specimen Lab is the Three.js lab for Sketchfab models: animal cells, organs, DNA, engines, space hardware, and more. Numbered pins mark parts. Tap a number to zoom and read what it is. Drag pins if a label sits off.

What it is

A dedicated 3D workspace at /games/3d-lab/. Catalog of specimens by subject; WebGL viewer with orbit, zoom, and pin callouts.

  • 33+ specimen entries in catalog
  • Filters: Anatomy, Biology, Chemistry, Space…
  • CC-licensed Sketchfab / NASA assets
  • Pin editor + JSON export for placement

How a student uses it

  • Open 3D Lab from the landing page
  • Pick a specimen from the left rail
  • Drag to orbit, scroll to zoom
  • Tap a yellow number on the model
  • Read the part name and description
  • Reset view / Show all as needed

What you see on screen

  • Left: Specimens list + filters
  • Center: 3D stage + numbered pins
  • Right: Parts list + pin editor
  • Top: specimen name, ভাষা, Games
  • Hint: Drag · Scroll · Tap a number

Teacher / editor tools

  • Place pins mode on the mesh
  • Drag pins to correct placement
  • Name + “what this is” fields
  • Download JSON to bake labels
  • Pins can persist in this browser

Example in the snapshot

Animal cell (Biology) shows organelles with pins 1-10: plasma membrane, nucleus, nucleolus, ER, Golgi, cytoplasm, mitochondrion, lysosome, vesicle, centrosome. Same lab also hosts heart, brain, DNA, solar system, V8 engine, lab glassware, and classroom instruments - one viewer, many subjects.
