GyanQuest Feature sheet 01 / 04
Canvas 2D Game

Canvas 2D missions you play, not watch

Every subject game runs in the browser as an interactive Canvas 2D lab: drag, sort, grow, score, and retry. Missions follow a 10-step path with a coach panel, step rail, hints, and progress that saves on the device.

What it is

HTML5 Canvas scenes drawn in real time (no Unity install). Shared engine powers 28 subject games with the same mission hub pattern.

  • Mission hub with playable cards
  • 10 steps per mission (Bruner spirals)
  • Coach Bio + side activity card
  • Step rail locks until you finish

How a student uses it

  • Open a game (example: Bio Explorer)
  • Choose a mission, tap Start
  • Act on the canvas: tap, drag, sort, grow
  • Read coach prompts; use Hint if stuck
  • Continue through all 10 steps
  • Progress restores after reload

What you see on screen

  • Viewport: the interactive lab (Canvas)
  • Coach: short spoken-style guidance
  • Activity card: narration + controls
  • Steps: 1-10 with lock / current state
  • Ask: tutor FAB always available

Pedagogy + tech

  • Learn-by-doing: fail, retry, prove
  • English / বাংলা language modes
  • Works on phones and shared devices
  • localStorage save (save-v2)
  • Optional login sync via API

Example in the snapshot

Bio Explorer · Living or Not · Step 1 places four suspects (flame, crystal, virus, sleeping cat) on a desk. Students start the investigation on Canvas, then move into sort, tree-vs-rock growth, mushroom proof, MRS GREN, and harder cases. The same Canvas pattern is reused across Force Fighter, Chemistry Lab, Math Quest, and the full library.
