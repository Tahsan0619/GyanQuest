# Sketchfab 3D models to download

**544 downloadable models** for GyanQuest / ImpactX (~10× the original list).

Save each download into this folder (`sketchfab models/`), one subfolder per model.

**How to download:** open the link → log in → **Download** → pick **glTF** (best for the web / Three.js).
Only models marked downloadable on Sketchfab are listed.

**License:** prefer **CC-BY** or **CC0**. Credit the author if you ship the model.
**CC-BY-NC** is classroom-OK but not for commercial products. Skip a file if Download is gone.
